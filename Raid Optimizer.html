ℹ️ How it works

Clears every animal with raids. The plan that loses the least (training cost of dead units) wins; among equal losses, the one using the fewest units. The quick plan updates as you type; 🔎 Deep search checks every sequence of up to Max waves and replaces it with the proven best. 🚂 Train: all waves leave together and each unit goes once. 🔁 Vasca: waves go one after another and survivors go again. 🛡️ On: chance the oasis is spawning and what could appear by the hit; ➕ adds it to the plan (not to the saved oasis).

ℹ️ How it works

Tolerance: how much net profit you give up to send fewer troops. 0 = maximum profit. Travel time is shown for information only and never affects the recommendation.

⚙️ Settings: Server, Units, Bounty & Base Defence

Game server is used for the ↗ links that open an oasis in the game (any address from your server works; only the server part is used). Base defence is added to the animals' defence (10 is the village value; check once against the in-game simulator with defender Nature and set 0 if it doesn't match). Troop speed × is your server's troop speed multiplier. Map size is used for wrap-around distances (standard maps are 401 × 401).

Adjust unit costs, speeds and bounty values if they differ on your server. Bounty is the total per animal, paid equally in the four resources.

Saved oases and villages are kept.
